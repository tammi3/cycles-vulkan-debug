TWO ROOT-CAUSE FIXES DURING DEBUG (both were TEST-HARNESS bugs, not port bugs):
1. Crash 0xC0000005 in path_rng_1D: instance2.xml's real sampling_pattern is
   TABULATED_SOBOL (=1), so the host reference path_rng took the tabulated branch
   and dereferenced a NULL kernel_data.tables pointer. Fix: OVERRIDE
   sampling_pattern to SOBOL_BURLEY (0) in BOTH the GPU MathParams and the host
   reference KernelData (like the pixel_jitter override), so both sides exercise
   the in-scope SOBOL_BURLEY branch like-for-like. TABULATED_SOBOL branch is NOT
   covered (out of S1a scope; table not passed to shader).
2. VUID-vkDestroyDevice-device-05137 (leaked child object): the probe's fence was
   a local, never destroyed. Fix: moved the fence into the MathProbeResources RAII
   struct so it is destroyed on all paths. VUID count went 1 -> 0.
